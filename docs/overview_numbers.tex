\begin{itemize}
\item \textbf{Пре-регистрация в основном не подтвердилась.} Из 17 подтверждающих тестов поправку Холма проходят 4: декодируемость и валидность записи для STATE, проверка восприятия для REC и JEPA. Пре-регистрированная оценка (кривизна предсказанной высоты) оказалась слишком шумной выше диапазона и смещённой ниже него. Она не различает <<прилипание>> и <<закон>>, а правило локуса выдаёт метки без устойчивой картины. Это промах дизайна, он честно описан в ограничениях статьи.
\item \textbf{Все три семейства компетентны} внутри диапазона (гейт пройден), гравитация читается из belief'а: $R^2=0{,}59$ для STATE против 0{,}08 у необученной динамики.
\item \textbf{Восприятие не виновато}: на кадрах вне диапазона позиции читаются так же точно (добавка 0{,}01 [-0{,}07; 0{,}09] px у REC, 0{,}09 [-0{,}11; 0{,}29] px у JEPA).
\item \textbf{Belief отслеживает гравитацию вне диапазона, но занижает её примерно вдвое}: наклон пробы 0{,}50 [0{,}43; 0{,}56] сверху и 0{,}74 [0{,}58; 0{,}87] снизу (STATE), у пиксельных семейств так же. Это самое точное число в работе. Оговорка: проба на замороженных признаках V-JEPA~2 занижает в похожей степени, так что часть эффекта может быть геометрией кода, а не <<неверием>> модели.
\item \textbf{Модели не прилипают и не следуют закону} (разведочная метрика $\lambda$). Выше диапазона предсказания проходят около половины пути от прилипания к закону (0{,}55 / 0{,}70 / 0{,}53 для STATE / REC / JEPA), ниже диапазона остаются у границы (0{,}28 / -0{,}16 / 0{,}13).
\item \textbf{Провал поделён между выводом и исполнением} (разведочно). У STATE, единственного семейства с валидной записью, запись истинной гравитации в belief поднимает $\lambda$ выше диапазона с 0{,}55 до 0{,}85, это уровень модели-близнеца WIDE, обученной на $g\in[1,12]$ (0{,}80). Ниже диапазона даже оптимизированный belief закрывает лишь 43\,\% [35; 52] разрыва до WIDE (REC 54\,\% [32; 74], JEPA 53\,\% [41; 63]).
\item \textbf{Гипотеза <<масштаб не покупает экстраполяцию>> не подтвердилась.} Ошибка внутри диапазона падает примерно на 2 px за декаду данных (STATE: 10{,}8 / 8{,}6 / 6{,}3 px при 1k / 8k / 100k эпизодов), а $\lambda$ выше диапазона при этом растёт (0{,}24 / 0{,}39 / 0{,}55). Размер сети динамики не помог, линейная рекуррентность (LRU) ухудшила.
\item \textbf{Энергию не сохраняет никто}: медианная относительная ошибка энергии растёт с 0{,}17 до 0{,}39 за 80 кадров (STATE). Линейной ручки для горизонтальной скорости не нашлось.
\end{itemize}
